# Проверка сертификата Smart Bridge полностью на телефоне

В Android TEST, раздел «ИСНА · тестирование»:

1. «Получить SOAP с TEST-сервера и подписать локально» — выбери свой .p12.
2. «Проверить подписанный SOAP на TEST VPS» — сервер вернёт SHA-256
   только открытого сертификата из подписанного SOAP.
3. «Сравнить .cer с подписанным SOAP · на телефоне» — выбери публичный
   .cer/.crt/.pem/.der, который предположительно зарегистрирован в Smart Bridge.

Приложение через штатный Android ACTION_OPEN_DOCUMENT читает этот файл только
на телефоне, канонизирует его через X.509 CertificateFactory в DER и вычисляет
SHA-256. Только контрольные значения сравниваются в памяти Flutter.
Сам файл .cer не передаётся ни в Nika Business VPS, ни в ШЭП, ни в чат,
не сохраняется приложением и не попадает в логи. Выбор .p12/.pfx/.key
запрещён, размер файла ограничен 64 КБ.

- Совпадение подтверждает, что выбранный .cer соответствует сертификату
  открытого ключа из подписанного SOAP. Это не подтверждает, что именно
  этот .cer зарегистрирован в Smart Bridge и что ШЭП примет SOAP.
- Несовпадение блокирует кнопку повторного TEST POST для данного SOAP.
- Сертификат из предыдущего теста истекает 04.11.2026, поэтому проверить
  срок действия и затем обновить/актуализировать регистрацию будет важно.

Production / настоящая подача ФНО не изменены.
